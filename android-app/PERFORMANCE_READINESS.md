# Loqata Android v0.3 Performance

هذه النسخة تركز على الأداء والثبات قبل التجميل.

## ما تم إضافته
- ProductRepository منفصل بدل تحميل المنتجات مباشرة داخل الشاشة.
- Cache محلي للمنتجات، بحيث تظهر آخر نسخة محفوظة فورًا.
- Fallback للمنتجات عند انقطاع الإنترنت.
- Retry تلقائي لاتصال الشبكة على مستوى OkHttp.
- Timeouts أقصر وأنسب للموبايل.
- RecyclerView caching لتحسين السلاسة.
- منع الضغط المكرر على زر Checkout.
- منع تكرار طلب OTP أثناء وجود طلب جارٍ.
- منع تكرار إنشاء الطلب.
- فحص وجود الإنترنت قبل OTP وإنشاء الطلب.
- Lifecycle guards لمنع تحديث شاشة مغلقة بعد رجوع استجابة الشبكة.
- الإبقاء على حفظ السلة وبيانات العميل.
- HTTPS فقط.
- لا توجد أسرار SMS/Paymob داخل التطبيق.

## ما لم يتم ادعاؤه
- لم يتم بناء APK/AAB داخل هذه البيئة.
- لم يتم قياس startup time على جهاز Android حقيقي بعد.
- لم يتم إجراء اختبار ضغط فعلي على Backend بعد.

## الاختبار التالي
1. فتح المشروع في Android Studio.
2. تشغيل Debug على جهاز Android حقيقي.
3. فتح التطبيق بدون إنترنت بعد تحميل المنتجات مرة واحدة.
4. تجربة إضافة منتجات وإغلاق التطبيق وإعادة فتحه.
5. تجربة الضغط السريع المتكرر على OTP والتأكد أن الطلب لا يتكرر.
6. إجراء طلب كامل بعد اعتماد Sender ID وتشغيل SMS Misr.
