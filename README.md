# متجر لقطة — الإصدار 1.7.0

نسخة محسّنة من متجر لقطة تعمل مباشرة في المتصفح دون خادم.

## الجديد
- تحسين عرض المنتجات على الموبايل.
- دعم روابط صور حقيقية للمنتجات مع بديل إيموجي.
- تطوير إدارة المنتجات: الاسم والسعر والقسم والوصف والصورة.
- إدارة الطلبات وتغيير حالتها وحذف المكتمل.
- لوحة إحصائيات للمبيعات والطلبات والمنتجات الأكثر طلبًا.
- حفظ البيانات محليًا باستخدام localStorage.

## التشغيل
افتح `index.html` في المتصفح أو ارفع الملفات إلى GitHub Pages.

> ملاحظة: البيانات محلية على نفس الجهاز والمتصفح، والطلبات تُرسل عبر واتساب إلى الرقم المخصص داخل `app.js`.
