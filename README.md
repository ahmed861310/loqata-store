# لقطة v1.3.0

إضافة صفحة تفاصيل المنتجات لمتجر لقطة.

## الجديد
- زر "عرض التفاصيل" لكل منتج.
- نافذة تفاصيل متجاوبة مع الموبايل.
- وصف وسعر المنتج.
- إمكانية إضافة المنتج إلى السلة من صفحة التفاصيل.
- إغلاق النافذة بزر الإغلاق أو الضغط خارجها أو زر Escape.

## التشغيل
افتح `index.html` في المتصفح أو انشر الملفات على GitHub Pages.
