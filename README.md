# لقطة V1.1

نسخة ثابتة مناسبة لـ GitHub Pages وتعمل من ملفات HTML/CSS/JS فقط.

الموجود:
- واجهة عربية RTL.
- بحث عن المنتجات.
- أقسام المنتجات.
- سلة مشتريات.
- حفظ السلة في LocalStorage.
- تعديل الكميات وحذف المنتجات.
- إرسال الطلب عبر واتساب.
- تصميم متجاوب للموبايل.
- لا تحتاج إلى خادم أو قاعدة بيانات لتشغيل النسخة التجريبية.

## الرفع على GitHub Pages من الموبايل
1. فك الضغط عن الملف.
2. افتح مستودع GitHub الخاص بالمشروع.
3. ارفع `index.html` و`style.css` و`app.js`.
4. من Settings > Pages اختر النشر من الفرع الذي يحتوي الملفات.
5. افتح رابط GitHub Pages بعد اكتمال النشر.
